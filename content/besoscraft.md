**BE$O$craft** is a separate survival server created on 1 April 2024 as the April Fools' joke of [[Season 3]]. It was named after the character [[beso|Be$o$]], one of that season's antagonists.

The server requires game version *Beta 1.7.3*, and you can join it at the address `betasektionen.se`. Apart from that it is a completely normal server, without plugins.

## Announcement

The following announcement was posted on the Discord server on 1 April 2024:

```markdown
@everyone

# :besos: METACRAFT IS DEAD, LONG LIVE BE$O$CRAFT :besos:

Those of you who logged into the server at some point in March have definitely noticed two things:

1. A block disappeared from the ruins of the Architecture building.
2. Not a single living person has been on the server. (Yes, including you! Sorry you had to find out like this.)

In light of the above, we have decided to **shut down METAcraft permanently.** But fear not! It is being replaced by **BE$O$craft**, an exciting new concept running the best game version of all time: **Beta 1.7.3**! You can join the new (old) server right now, just follow the instructions below!

## The instructions below
1. Go to the settings in your Minecraft launcher
2. Turn on "historical versions"
3. Create a new installation for Beta 1.7.3 (b1.7.3)
4. Ignore Mojang's warnings about "player safety features" (more like 1984 features)
5. Connect to `betasektionen.se`!
```
