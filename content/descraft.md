**DESCraft** (or "the DESC server") was a Minecraft server run by DESC from 2017 to 2021. It was started by Simon Mossmyr (DESCtop at the time) and went through several iterations (what METAcraft now calls seasons).

Almost all the information on this page was gathered from the #minecraft-server channel on DESC's Discord server.

## Timeline

### Iteration 1

* **3 March 2017**: the server was started for the first time. It is unclear exactly which game version was used, but 1.11.2 was the latest version on that date.
* The server's IP address changed several times during the academic year, because it had accidentally been configured as dynamic.
* **4 February 2018**: the server moved to a new host.
* It is unclear exactly when the server was shut down, but on 15 January 2019 Simon said that it had been dead "for a while".

### Iteration 2

* **15 January 2019**: the server was started with a new world and a new IP address, on game version 1.13.2. It was hosted on "an old office computer standing on my [Mossmyr's] bedroom floor".
* **3 March**: the Ender Dragon was killed on the server.
* **4 June**: the server was updated to 1.14.
* The server was shut down some time before **19 September 2019**, as nobody played on it and interest was generally low.

### Iteration 3

* **24 October 2019**: starting a new server was discussed on DESC's Discord server. Christian (DESCtop at the time) suggested talking to Plutten (the chapter's system administrator at the time) to "check whether we can run a server on the chapter's servers" (on AWS).
  * Plutten later replied that the chapter's AWS "doesn't have enough storage".
* **2 November**: Jonas and Ellinor created a temporary Aternos server while waiting for someone to set up a proper one. It is unclear how many people played on it.
* **12 December**: Simon began setting up a new server on a physical computer.
* **20 December**: the server was started on game version 1.15.
* **24 February 2020**: the server was updated to 1.15.2.
* **15 March**: the server crashed. While waiting for Simon to restore it, Sengee created [a new server](#ftb-ultimate-reloaded-server) to play on.
* It is unclear when this server was shut down. Simon sent the last Discord message on **31 March 2020**, asking whether anyone was playing on DESCraft, since there were more players on Sengee's new server.

### Iteration 4

**9 December 2020** is the last time DESCraft was mentioned on the Discord server: the server was started once more, now on version 1.16.4. It is unclear whether this was the same world as Iteration 3 or a new one, and there is no information at all about when the server was shut down.

Interest in the server was probably taken over by [[Season 1]] of METAcraft.

## Technical

### Mods and plugins

No client-side mods were required for any iteration of DESCraft. There were no server-side plugins in iterations 1, 2 and 4 either, but it is unclear whether a "greylist" plugin was added in iteration 3.

### Hosting

Every iteration of DESCraft was hosted by Simon on a personal computer.

After the server crash in Iteration 3 on **15 March 2020**, Sengee created a new Minecraft server with the modpack *FTB Ultimate Reloaded*, plus *Tinkers' Construct* and *Mantle*. It ran game version 1.12.2 with Forge as the mod loader, and you had to join a network through ZeroTier One to connect. It existed alongside Simon's DESCraft.

The server closed on **7 April 2020**, after most people had stopped playing. On 3 March 2021 Sengee published a [download link for the world](https://drive.google.com/file/d/1x-XeiAQT4wqIG-KjwPlGVm5ixdKSE_e3/view?usp=sharing).
